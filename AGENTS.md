# Repository instructions

## Language

Maintain all repository content in English, regardless of the language used in user prompts or conversations with Codex.

- Write documentation, code comments, configuration comments, examples, and user-facing messages in English.
- Use English for new identifiers, commit messages, and pull request titles and descriptions.
- Translate existing Polish prose into English when updating it, preserving its meaning, commands, links, and technical details.
- Keep literal external names, URLs, paths, and required API identifiers unchanged.
- Conversation replies may follow the user's language; content saved to this repository must be in English.

## Commit privacy

- Use the account's GitHub-provided `noreply` email for both author and committer metadata.
- Before creating or pushing commits, check the effective Git email configuration and ensure no personal email address is included in the new commits.
- GitHub's "Keep my email addresses private" setting does not replace local Git email configuration.
